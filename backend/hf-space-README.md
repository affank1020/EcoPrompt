# EcoPrompt API

FastAPI backend for EcoPrompt: prompt complexity classification (`/analyse`, `/analyse/bulk`) and prompt compression (`/compress`). Every endpoint except `/` requires an `X-API-Key` header.

Uploaded to the Space as `README.md` from `backend/` in the EcoPrompt repo; see `docs/DEPLOYMENT.md` there.
